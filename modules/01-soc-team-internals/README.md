# SOC Team Internals

Ce dossier contient mes notes et analyses pour le module **SOC Team Internals** du parcours **SOC Level 1** de TryHackMe.

Ce module introduit les compétences essentielles d'un analyste SOC L1 pour traiter des alertes dans un environnement SOC : triage, classification, reporting, escalade, utilisation de ressources internes et compréhension des objectifs d'un SOC.

> Les notes de ce dossier ne contiennent pas de solutions complètes, de flags ou de réponses directes aux rooms. Elles sont orientées compréhension, méthodologie et retour d'expérience.

## Contenu du module

| Room | Description | Note |
|---|---|---|
| SOC L1 Alert Triage | Comprendre les alertes SOC et construire une approche systématique pour les trier efficacement. | [Voir la note](01-soc-l1-alert-triage.md) |
| SOC L1 Alert Reporting | Apprendre à reporter, escalader et communiquer correctement autour des alertes SOC à haut risque. | [Voir la note](02-soc-l1-alert-reporting.md) |
| SOC Workbooks and Lookups | Découvrir les ressources internes permettant de structurer et simplifier le triage d'alertes L1. | [Voir la note](03-soc-workbooks-and-lookups.md) |
| SOC Metrics and Objectives | Comprendre les métriques clés qui mesurent l'efficacité d'un SOC et les leviers d'amélioration. | [Voir la note](04-soc-metrics-and-objectives.md) |
| Introduction to Phishing - SOC Simulator Scenario | Découvrir le fonctionnement du SOC Simulator à travers un premier scénario de triage d'alertes. | [Voir la note](05-introduction-to-phishing.md) |
